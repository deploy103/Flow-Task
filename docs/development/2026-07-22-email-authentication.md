# 이메일 인증 및 비밀번호 찾기 개발 기록

## 범위

- 이슈 #33, PR #34
- PostgreSQL 자체 인증을 유지하면서 회원가입 이메일 소유권 확인과 비밀번호 복구를 추가했다.
- 제공된 Resend 설정은 운영 환경변수로만 연결하고 실제 API 키·발신 주소는 저장소에 포함하지 않았다.

## 설계와 보안 검토

- 인증 링크 24시간, 비밀번호 재설정 링크 30분의 만료 시간을 적용했다.
- 토큰 원문 대신 SHA-256 해시만 저장하고 일회용 소비를 serializable 트랜잭션으로 처리했다.
- 메일 보안 스캐너가 GET 링크를 방문해도 계정 상태가 바뀌지 않는다. GET은 확인 화면만 표시하고 실제 인증은 CSRF 보호 Server Action에서 수행한다.
- 인증 메일 재요청과 비밀번호 찾기는 계정 조회부터 외부 메일 발송까지 응답 이후 작업으로 실행해 응답 시간 기반 계정 열거를 막았다.
- 비밀번호 변경 시 모든 기존 세션과 남은 재설정 링크를 폐기한다.
- 기존 사용자는 마이그레이션에서 인증 완료 상태로 보존하고 이후 신규 가입자만 인증을 요구한다.

## 검증

- 타입 검사, ESLint, 프로덕션 빌드
- 전체 단위 테스트
- PostgreSQL 통합 테스트: 발급, 교체, 만료, 재사용, 동시 소비, GET 무변경, 비밀번호 해시 변경, 전체 세션·잔여 토큰 폐기
- CI 비밀 스캔
- dependency audit 0건 (`sharp` 보안 수정 버전 고정)
