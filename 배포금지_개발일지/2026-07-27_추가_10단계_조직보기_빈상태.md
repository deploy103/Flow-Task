# 추가 10단계 개발일지 — 조직 보기와 빈 상태 개선

## 문제

- 공통 메뉴의 `조직 만들기`는 기존 조직을 확인하려는 사용자도 생성 화면으로 보냈다.
- 가입 조직이 없는 사용자는 대시보드의 설명을 읽고 별도 위치의 가입 폼을 찾아야 했다.
- 시스템 관리자가 일반 소속 없이 접근할 수 있는 조직을 한 화면에서 구분하기 어려웠다.

## 구현

- 데스크톱 사이드바와 모바일 하단 메뉴를 `조직 보기`로 바꾸고 `/organizations`에 연결했다.
- 전용 조직 목록에서 활성 소속만 조회하며, 보관된 조직은 노출하지 않는다.
- 시스템 관리자는 직접 가입한 조직과 관리자 권한으로 접근 가능한 조직을 구분해 확인한다.
- 가입 조직이 없으면 `가입된 조직이 없습니다` 안내와 `새 조직 만들기`, `초대 코드로 가입` 행동을 바로 제공한다.
- 조직이 있어도 같은 화면에서 새 조직 생성과 초대 코드 가입을 이용할 수 있다.
- 조직 카드에 역할, 구성원 수, 설명을 표시해 열기 전에 대상을 구분할 수 있게 했다.
- 탈퇴 등으로 비활성화된 소속 기록은 카드의 구성원 수에서 제외하고, 현재 활동 중인 구성원만 표시한다.
- 초대 코드 오류는 내부 원인을 노출하지 않으면서 사용자가 고칠 수 있는 문구로 안내한다.

## 검증

- 조직 목록 내비게이션의 정확·하위 경로 활성 상태 단위 테스트
- 활성/비활성 소속이 섞여도 활성 구성원만 집계하는 공통 쿼리 옵션 회귀 테스트
- TypeScript 타입 검사, ESLint, 전체 단위 테스트, 프로덕션 빌드
