# 추가 13단계 개발일지 — 시스템 관리 운영 통제

## 구현

- 시스템 관리자 대시보드에 전체 활성 소속과 운영 중인 과제·질문 집계를 추가했다.
- `전체 감사 로그` 화면을 추가해 최근 12건을 넘어 전체 운영 변경 이력을 조회할 수 있다.
- 작업자 이름/이메일, 작업 코드, 대상 종류/ID, 조직 이름으로 검색한다.
- 작업, 대상 종류, 활성/보관 조직으로 세부 필터링한다.
- 조회 결과는 한 페이지에 50건으로 제한하고 필터를 유지하는 이전/다음 페이지 이동을 제공한다.
- 조직 범위 로그에서 해당 조직으로, 사용자 대상 로그에서 사용자 관리 화면으로 이동한다.

## 보안과 개인정보

- 화면과 레이아웃 모두에서 시스템 관리자 권한을 서버로 검증한다.
- 검색어는 최대 100자, 페이지는 1~10,000 경계로 정규화한다.
- 조직 필터는 UUID를 검증하고 반복 query parameter는 첫 번째 값만 사용한다.
- 감사 로그의 `metadata`는 제목적 운영 화면에 노출하지 않으며 비밀번호, 토큰, 제출 내용을 조회하지 않는다.

## 검증

- 감사 로그 query 정규화, 경계, 반복 파라미터 단위 테스트
- TypeScript, ESLint, 전체 테스트, 프로덕션 빌드
