# 추가 8단계 개발일지 — 핵심 UI·UX 단순화

## 문제

- 조직 내부 화면에는 조직별 공통 메뉴가 없어 다른 기능으로 이동하려면 조직 홈을 반복해서 거쳐야 했다.
- 조직 홈에서 일반 활동과 관리자 기능이 같은 카드 목록에 섞여 우선순위를 파악하기 어려웠다.
- 과제 생성 화면은 전체 구성원을 대상으로 선택해도 개별 구성원 목록을 항상 표시했다.

## 구현

- 조직 내부에서 개요, 과제, 공지, 일정, 질문과 부서로 바로 이동하는 가로 내비게이션을 추가했다.
- 현재 조직과 메뉴를 경로에서 판별하고 `aria-current`로 현재 위치를 전달한다.
- 작은 화면에서는 조직 메뉴를 가로 스크롤할 수 있어 하단 공통 메뉴와 겹치지 않는다.
- 조직 홈을 구성원용 `활동`과 권한이 있는 사용자용 `조직 현황 및 관리`로 분리했다.
- 과제 생성 시 `구성원 직접 선택`을 고른 경우에만 구성원 목록을 표시한다.
- 조직 경로 추출과 조직 메뉴 활성 상태에 대한 회귀 테스트를 추가했다.

## 권한과 입력 검증

- 조직 내비게이션은 사용자가 접근 가능한 조직 목록에 포함된 조직에서만 표시한다.
- 관리자 카드 노출은 기존 서버 권한 판정 결과를 그대로 사용한다.
- 과제 대상 및 구성원 ID는 기존 서버 스키마와 조직 소속 검사에서 다시 검증한다.

## 검증
