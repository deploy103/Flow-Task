# 추가 14단계 개발일지 — 초대 코드 수명주기 관리

## 운영 점검

- 조직 초대는 발급과 사용만 가능했고 관리자가 발급 이력·사용량·만료 상태를 확인하거나 유출된 코드를 폐기할 방법이 없었다.
- 구성원 관리에 필요한 최소 운영 기능으로 초대 코드 현황과 즉시 폐기를 추가했다.

## 구현

- 구성원 관리 화면에서 최근 초대 50건의 역할, 사용량, 만료 시각, 발급자와 상태를 조회한다.
- 활성, 사용 완료, 기간 만료, 폐기 상태를 한 곳에서 구분한다.
- 활성 초대만 폐기할 수 있으며 처리 후 감사 로그를 남긴다.
- 원본 초대 코드와 해시는 목록 조회와 화면에서 모두 제외했다.

## 보안

- 화면 진입 권한 외에 폐기 트랜잭션 안에서 실행자의 최신 시스템 역할과 조직 소속 역할·상태를 다시 확인한다.
- 초대 ID와 조직 ID를 함께 조회하고 갱신해 다른 조직 초대에 대한 IDOR를 차단한다.
- 조건부 `updateMany` 결과가 정확히 1건일 때만 감사 로그를 기록해 동시·반복 폐기를 방지한다.
- 서버에서도 미만료·미소진 상태를 확인하고, 읽은 만료·한도·사용량을 갱신 조건에 고정해 상태 경쟁을 차단한다.
- 보관된 조직과 이미 폐기된 초대는 변경하지 않는다.

## 검증

- 초대 상태 우선순위와 만료·소진 판정 단위 테스트
- 정상 폐기의 조직 범위 및 감사 로그 테스트
- 실행자 권한 회수와 다른 조직 초대 접근 회귀 테스트
- 만료·소진 초대의 조작된 폐기 요청 차단 테스트
- 전체 테스트, TypeScript, ESLint, 프로덕션 빌드
